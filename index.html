Settings

MGO2 stage files are decrypted with a key named after their stage folder. It is found from the folder path (or by trying the folder names you opened); set it here only for copies kept outside the stage/<name> layout under an unrelated name.

Some MGS4 layouts (converted from Flash) contain mask / guide shapes, marked by extra bits in their object type, that the game never draws. They are hidden unless this is ticked.
